# Frontend AI Capstone

## About

This repository contains my capstone project for the FlyRank Front-end AI Engineering Internship.

## Goals

- Learn Git
- Learn GitHub
- Learn AI-assisted development
- Build frontend projects
- Always explain code before writing it

## Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Git
- VS Code
## Learning Objectives

This repository will be used to practice Git, GitHub, Node.js, and AI-assisted frontend development.
## Project Rules Learned

1. Always validate required fields such as Name and Email before allowing the form to be submitted.

2. Use clear labels, proper spacing, and consistent styling to improve accessibility and user experience.

3. Test AI-generated code before accepting it, and manually verify validation, edge cases, and functionality.
